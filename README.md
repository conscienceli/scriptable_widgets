# scriptable_widgets

给 [Scriptable](https://scriptable.app) (iOS) 写的 Widget 合集。每个 Widget 一个目录，自带说明和预览图。

| Widget | 尺寸 | 说明 |
|---|---|---|
| [**GeekBoard**](GeekBoard/) | Large | 极客风高信息密度面板：日程 · 提醒 · 农历节气 · 天气 · AQI · 经纬度海拔 · 月历 · 股票（含盘前盘后）与加密货币 · 活动圆环 · 网络 VPN。尺寸自适应各机型 |

## 通用安装方式

1. App Store 安装 **Scriptable**。
2. 把对应目录下的 `.js` 文件放进 iCloud Drive → `Scriptable/`（或在 App 内新建脚本粘贴内容）。
3. 在 App 内运行一次，按提示授予权限。
4. 桌面长按 → 添加小组件 → Scriptable → 选对应尺寸 → 长按小组件 → 编辑 → 选择脚本。

各 Widget 的配置项、可选依赖（如快捷指令桥接）见其目录内的 `README.md`。

## 设计原则

- **信息密度优先**：不放装饰性元素，不重复系统已有信息（例如状态栏已有的时间和电量）。
- **颜色即语义**：每种颜色对应固定含义，不做纯装饰上色；底色只用来划分区块边界。
- **尺寸自适应**：按机型算出 Widget 实际尺寸，再推导字号与分栏，不写死像素。
- **省电**：所有网络请求带 TTL 缓存，定位用低精度 + 缓存，无动画、无轮询。
- **优雅降级**：任何数据源失败时回退到缓存并标记，绝不整块空白或显示假数据。
- **不造假数据**：iOS 沙盒拿不到的东西（微信/短信未读、耳机电量、指南针、网关）直接不显示。
